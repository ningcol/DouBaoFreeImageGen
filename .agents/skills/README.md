# Agent Skills

Skills contain replaceable procedures for recurring work.

PACT governance defines **what must remain true**. Skills define **how to accomplish a task with today's models and tools**.

Examples:

- discovery;
- frontend visual review;
- architecture review;
- convergence review;
- documentation gardening;
- worktree merge review.

Skills may be simplified, replaced, or removed as agent/tool capabilities improve.

Do not move stable product truth or authority policy into a skill.
